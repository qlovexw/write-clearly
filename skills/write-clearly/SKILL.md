# 清晰写作

减少妨碍理解的语言压缩，让读者更容易恢复对象、动作、关系与条件。保留有效的术语和简洁表达；必要时增加几个词，而不以最少字数为目标。

主体来自 Clark、Martin 与 Mahowald（2026）[第 3.1 节](https://arxiv.org/html/2610.29162v1#S3.SS1)的六类语言特征。下列编辑动作是实践转化；中文部分是适配判断，不是该英语研究直接验证的规则。

## 先确定取舍

- 采用已有的读者、用途、语气和长度要求；缺省时按任务推断。新写依据材料组织信息；改写保留原结论及其强度。只评价或只改局部时守住范围。
- 优先级：原意和内容准确 → 关系清楚 → 文体合适 → 文字简洁。不为顺口新增事实、因果、责任、承诺或确定性。
- 保留学术专有名词、行业术语、作者明确定义的名称、符号、产品名和代码标识符。可以解释名称，不能换成近义词、比喻或自创标签。
- 区分领域术语、作者定义名和未定义的临时拼接语。只对第三类尝试还原；归类不明时保留名称，先改周围句法。材料不足以确定含义时，提出具体疑问，不猜改。
- 保留条件、否定、数量范围、时间顺序、比较基准、语气与不确定性。发现可能的内容错误，在正文外指出，不以清晰化名义静默纠正。

## 六类特征：有理解障碍才编辑

每类都按“是否让目标读者猜关系 → 能否依据原材料展开 → 是否保持含义”决定。特征出现本身不构成错误，也不要求逐类改出痕迹。

### 1. 低频词组与不熟悉的搭配（N-gram statistics）

- **触发**：临时搭配省掉了关系词，或把已有信息包装成读者难以还原的抽象说法；不是仅因某个词少见。
- **动作**：依据上下文写出对象、动作或关系；补回必要的介词、连词和说明，删除不增信息的抽象复述。
- **英文**：检查整段搭配是否自然、关系是否可辨；不要用通用词频推断专业语境中的难度。
- **中文适配**：检查生造组合、翻译式搭配及“推进／赋能／实现”等词周围被省掉的具体内容；这些词本身不禁用。
- **保留**：准确的专业词、作者定义名、必要的新概念，以及目标读者熟悉的搭配。不逐词换成常用词，也不使用禁词表。

### 2. 长依存（Dependency length）

- **触发**：读者必须跨过多层插入或修饰，才能找到主谓、动宾或条件与结论的对应关系。
- **动作**：把关键成分放近；前置或后移附加说明，必要时拆句。移动后核对每个条件与修饰语仍指向原对象。
- **英文**：优先检查主语与谓语、动词与论元被插入内容隔开的情况；句长不等于依存长度。
- **中文适配**：检查多层“的”、长前置条件和插入说明是否遮住主干；按语义调整位置，而非照搬英文语序。
- **保留**：层次清楚的长句、需要共同管辖的条件及正式文体。没有统一句长，也不为拆句丢掉否定或适用范围。

### 3. 宾语关系从句（Object relative clauses, ORCs）

- **触发**：英文中被修饰名词充当关系从句的宾语，省略关系词或层层嵌套使“谁对谁做什么”难辨。
- **动作**：先尝试补出可用的 that／which；仍难理解时，移出次要从句，或选用明确施事的被动表达。保留限制性与非限制性的原区别。
- **英文**：保留清楚的 ORC；省略关系词也可以清楚。这里的检查不等于把所有定语从句改为主句。
- **中文适配**：不把中文“的”字结构一律标成英文 ORC。只在嵌套修饰或施受关系不明时，展开为明确的小句或调整修饰位置。
- **保留**：清楚的关系结构及有助于突出当前话题的被动句。不强制主动句，不删掉从句承载的筛选条件。

### 4. 名词叠置（Stacked noun compounds）

- **触发**：多个名词连接后，所属、用途、位置或修饰层级需要读者猜测。
- **动作**：先把完整术语作为单位保留，再用介词、谓语或短小解释展开单位之间的关系；材料不能确定层级时先问清。
- **英文**：必要时补 for／of／in 等关系，而不凭名词顺序猜出原文未给的关系。
- **中文适配**：检查“名词＋名词”和多层“的”是否掩盖关系；不按英文名词数量阈值判错，也不机械插入“的”。
- **保留**：有限元分析、缓存一致性等完整术语，以及已有严格定义的复合名称。叠词数量不是拆开术语的理由。

### 5. 名词转成动词（Denominal verbs）

- **触发**：临时把名词当作动作，使读者不知道是创建、录入、检查、发送还是其他操作。
- **动作**：上下文已给出动作时，写出准确动词及其对象；没有给出时保留原词并指出缺项，不替作者选一种操作。
- **英文**：检查不熟悉的临时转用，保留目标读者熟悉且含义明确的用法，如 email。此类不是 nominalization（动词等转为名词）。
- **中文适配**：中文词类边界不同，只检查临时“把 X 表格一下”等说法是否省掉关键动作；“研究、测试、下载”等不因此受限。
- **保留**：约定俗成的动作用语、界面动作名、命令与代码标识符；不把行业动词普遍展开成笨重短语。

### 6. 无生命主语与通常要求有生命施事的动词（Inanimate subjects）

- **触发**：拟人或转喻把实际动作、机制或后果压缩成隐喻，迫使读者另行推断。
- **动作**：依据材料直接说明发生了什么；施事已知且相关时可以写出施事。无法确定机制时不补造机制或责任人。
- **英文**：重点检查无生命主语与该动词的搭配，而非所有无生命主语。The results indicate… 等常规表述可保留。
- **中文适配**：检查“数据拒绝解释”“流程吞掉责任”等表达是否遮蔽含义；按实际上下文展开，不机械改成“我们……”。
- **保留**：清楚的物理因果、惯常转喻、文体所需的拟人，以及“系统返回错误”等准确表达。无生命主语不自动构成问题。

## 篇章衔接：简短补充

长文先看信息顺序，再处理局部；让必要的对象和关系在读者需要时出现。同一对象稳定命名，指代有歧义才补出名称；只明示材料支持的条件、比较、因果或转折，不靠添加连接词制造关系。按用途安排段落，不固定要求先给结论或使用相同模板。

## 试写、复核与交付

1. 读取必要上下文，确定需保护的名称、事实和条件；新写先用材料形成可跟随的顺序。
2. 找到实际妨碍理解的压缩处，选择上述相关动作；改动已经足够时停止，清楚的文本允许原样保留。
3. 对照材料核对含义，再只读成文检查能否识别对象、动作和关系。数值或公式涉及分母、参照和单位时核对它们；报告涉及负责人、状态和期限时保留它们。只检查当前任务涉及的项目。
4. 默认交付可直接使用的正文；需要解决的歧义在正文外简短说明。用户要求诊断才展开诊断，不默认附台账、自评或逐句解释。

不把短句、主动句、常用词、口语化、删减比例或回译设为完成条件，不为降低 AI 检测分数而改写。叙事和创作遵循用户的节奏与留白要求。一般写作无需外部服务、自动替词或可读性评分。
